# PixelFlip

A simple but powerful browser-based **all-in-one** image converter

Features:
- Convert images to **PNG / JPEG / WebP**
- Crop + Rotate (90° per click)
- Effects: **grayscale**, **sepia**, **reflect**, **sobel**
- Filters: **blur**, **brightness**, **contrast**, **saturation**, **hue**


Notes

- GIF input converts the **first frame** (browser limitation via Canvas).
- HEIC support depends on the browser; Safari usually has better support.
- Large images can be memory-heavy; if a file fails, try fewer files at once.
